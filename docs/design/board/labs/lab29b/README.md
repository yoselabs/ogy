# Lab 29B: lab 28's look, lab 29's levels (throwaway prototype, tool-library data)
Open `lab29b-standalone.html` (one file, no server). Rebuild: `node build.mjs`. Check: `node qa/check.mjs` (real mouse and wheel, headless Chromium 1440x1000; shots land in `shots/`). The wheel zooms through three levels: Map (under 75%, cards by attention priority), Flow (a workflow opens into steps), Detail (135% and up: lab 28 screens, rows, badges). Drag pans, click selects, F fits, Relations (top right) lists every relation by its word.
1 Cards: icon + title, kind word small in the corner (`head`, `noteCard`), body by priority, dropped whole when it does not fit. 2 Labels: only ontology field words (realizes, for, actor, calls, covers ends, event, shows, create/write/delete/tell/transition); hover an arrow for what the field means. 3 Levels: the three above; a card shows only what its pixels allow, never the same sentence twice.
4 Remind/Notify: the ontology already splits it, so the board does too: a `calls` box, then rows that `covers ends` of the callee (Detail: two parts with a divider; Flow: a `calls` chip; Map: a purple `calls` arrow and a `covers ends` arrow); hover the box for the explanation. No new kind invented.
5 One name, one style: every mention goes through `mnSvg`/`mnHtml` (`core.js`): icon, title, kind colour. `qa/check.mjs` asserts every entry id renders the same text, class and colour everywhere and that no dashed key shows (prose such as "max-loans" is shown as "max loans"). 6 The question icon is 12px, not 17.
7 `VIEWS` in `cards.js` is the registry (kind by level); an entry never draws itself. 8 Titles: `title` if the ontology entry has one, else the key humanized, with a hint in the pinned card; one custom tooltip, no native titles; case words (Sent, Otherwise, Owes) kept; actor cards (Member, Mail relay) exist.
9-11 Effect badges (`badgeSvg`): one per thing touched, fields top to bottom with the value when known, no comma lists; create = green left edge only, delete = all red, edits and tells plain; simple icons (plus, pen, bin, envelope, arrow), header split from fields. The values (tool, renewals) are a lab example added in `model.js`: ogy's effect has no value field yet.
12-13 The Loan card draws its lifecycle as a graph: states are pills joined by arrows; below, each transition lists the workflows that fire it or start on it as links (workflow look, never the state look); a transition no effect fires shows a red "no effect fires it" (Return, today).
14 Stylesheet, colours, fonts, frames, steps, rows, end cards and sketch screens come from lab 28; levels, relations panel and actor/goal/capability cards from lab 29; blocks sit in columns with room for routed edges, so none overlap.
Machine check at default fit, 25%, 50%, 100%, 170%: zero overlaps, zero text crossed by an edge, zero edges entering a block, no text under 11px, no console errors; the auditor first proves itself on injected defects.
