    actors: [member, host, system]
    trigger: "member submits room, slot, attendees"

      rejected:     {result: failure, means: ?open {question: "host declines", assumed: "cancelled"}}

## Questions for the owner

- How late is "late" for cancellation, and what is the late fee (amount, formula, currency)?
- What makes a room "bigger"? Threshold in capacity or attendees, or a flag per room?
- Where does host approval sit in the order: before the hold, before payment, or after? Is there a state for awaiting approval (booking has only four states)?
- What happens if the host rejects, or does not answer in time? Is there a deadline?
- How long is a room held awaiting payment, and what happens on expiry (the booking state to cancelled)?
- What happens when Stripe is down, slow, declines, answers twice, or never answers?
- What if the SMS provider or Kisi fails: is the booking still confirmed, is retry wanted, can the member see the code in the app?
- Is the door code revoked in Kisi on cancel? Is the code per booking, and when does it become valid?
- Credits: how many per booking, what if balance is insufficient, are credits returned on cancel, does late cancel cost credits or a fee for premium members?
- Is a paid booking refunded on cancel (fully or partly)? Is the late fee charged to the Stripe payment or separately?
- Premium credit bookings: do big rooms still need host approval? Do they skip the hold?
- Can attendees exceed room capacity? Any limits on slot length or how far ahead one can book?
- Can members cancel a pending_payment booking, a finished one? When does confirmed become finished (end of slot, automatic)?
- Cleaner: how is the cleaner notified, how do they report done, is a room unbookable until ready, what if they cannot clean it?
- What does usage history show (period, fields, credits spent, fees)? Can only the member see it, or hosts too?
- Notes: can they be edited or added to after confirmation, length limit, how does the host get to see them, can the host reply?
- Who are members' other plans besides premium, and is there anything else besides Stripe and credits as payment?
- Which interfaces exist (member app, host screen, cleaner view, SMS) and what is the text of each end message?
- Who is the persona for the system (scheduler for "finished" transitions)? Any agent personas?
