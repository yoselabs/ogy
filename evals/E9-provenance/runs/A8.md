# A8: tool library capture (E9 provenance)

Conventions used in this run. The spec has no provenance field, so every entry and part carries `said: [n,...]`, the
sentence numbers of the owner's words it comes from. An entry with no `said` is an agent proposal (layer technical or
implementation) or an assumption. An unknown owner decision is `open` with `assumed` in force. A value whose `is` is
null is a number the owner has not given. Spec gap: provenance is not in the spec; `said` is my minimal addition.
